# ТриДэПросмотрщик в1.0

## Введение

Программа представляет из себя просмотрщик 3д моделей файлов .obj формата. Приложение написано исключительно в рамках образовательного курса Школы 21. Программа позволяет просматривать каркас моделей и показывает только вершины и грани фигур. \
Модули, такие как парсер файла и аффинные преобразования, написаны на языке C, в то время как графическая оболочка была собрана с помощью QT, а отрисовка 3д изображения использует OpenGl библиотеку.

## Установка

Для установки программы необходимо иметь gcc, make, qmake, QT версии 4 или выше предустановленными в системе. \
Все `make` команды должны выполняться в `src` директории.

Для установки приложения используйте команду `make install`. \
Установленное приложение будет находиться в папке `3DViewer_v1.0/3DViewer_v1.0` проекта. \
Для запуска используйте команду `make run`. \
В папке приложения также будут находиться некоторые примеры объектов `3DViewer_v1.0/models/`.

## Удаление

Для удаления используйте команду `make uninstall`.

## Дополнительно

- `make clean` - очищает все файлы созданные во время компиляции.
- `make dist` - создает архив `.tar`, содержащий все необходимые файлы для установки.
- `make distclean` - удаляет созданный архив.
- `make dvi` - открывает инструкцию.
- `make test` - выполняет интеграционные тесты для модулей. Использует утилиту `checkmk`.
- `make gcov_report` - запускает тесты и формирует отчет о покрытии кода. Использует утилиту `lcov`.
- `make style` - проверяет стиль кода на соответствие Google.
- `make memtest` - проверяет программу на утечки памяти запуская тесты. Использует `valgrind` или `leaks` утилиты в зависимости от ОС.
- `make memtest_app` - проверяет программу на утечки памяти запуская приложение.

## Описание

![Пример](./images/example.png "Пример")

1. Открыть файл `.obj`. Путь будет указан в текстовом поле.
2. Нажать `START` чтобы просмотреть модель. Кнопка `Reset` сбрасывает позицию и масштаб до изначальных.
3. Панель управления позволяет двигать модель по трем осям - сдвиг по оси, вращение вокруг оси и масштабирование. У маштабирования есть нижний и верхний предел. \
  Область видимости по оси Z тоже ограничена.
4. Настройки:

- Цвет вершин, линий и фона.
- Размер вершин и ширина линий.
- Тип проекции - центральная или параллельная.
- Тип вершин - круг, квадрат или отсутствует.
- Показать оси.
- Тип линий - сплошные или пунктирные. Имеется 8 типов пунктирных линий.
- Move camera on Z axis. Передвигать камеру по оси Z. ВАЖНО: если активно, позволяет камере следовать за движение модели по оси Z, \
  таким образом не допуская ситуации выхода модели из области видимости.

  Настройки сохраняются между запусками приложения. Кнопка `Default` используется для сброса настроек к дефолтным.

5. Приложение поддерживает экспорт изображений в JPEG, BMP форматах. \
  Также программа может обрезать небольшие скрин-касты в GIF формате (5 seconds, 10 fps, 640x480).
